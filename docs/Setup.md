# Setup Guide

## Clone Repository

```bash
git clone https://github.com/Adityachandkaushik/complete-observability-platform.git
```

## Build Containers

```bash
docker compose up --build
```

## Access

Application

```
http://localhost:5000
```

Prometheus

```
http://localhost:9090
```

Grafana

```
http://localhost:3000
```
